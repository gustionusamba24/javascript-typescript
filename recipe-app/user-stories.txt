Recipe App:
meaning: the description of application's functionality from user's perspective
format: As a <user type>, I want to <action>, so that <benefit>.

1. As a user, I want to search for recipes, so that I can find new ideas for meals.
2. As a user, I want to be able to update the number of servings in a recipe, so that I can serve the different number of people.
3. As a user, I want to bookmark my recipes, so that I can easily find them later.
4. As a user, I want to be able to create my own recipes, so that I have them all organized in one place.
5. As a user, I want to be able to see my bookmarks and my own recipes when I leave the app and come back later, so that I can close the app safely and not lose my data.
